# 조준을 넣은 분류기 — 무엇이 좋아졌고, 무엇을 알고 켜는가

조성원 (행동 AI) · 2026-08-12

---

## 한 장 요약

로그인 캡차 오탐이 실사용에서 18.9% 였다. 원인 두 개를 찾아 각각 고쳤다.

```
18.9%
  ├ 12.8%p  거부권 문턱이 잘못된 단위로 잡혀 있었다   → 고침 (9.7%)
  └  6.2%p  분류기가 짧고 곧은 궤적을 봇으로 읽었다   → 조준 구간을 넣어 고침
```

조준을 넣은 분류기는 전체 오탐 3.0% 에서 아는 공격을 0.0~7.1% 로 막는다.

**그러나 승격 기준 두 개를 못 넘겼고, 그걸 알고 켠다.** 무엇을 못 넘겼는지는 §4 에
숫자로 적었다. 이 문서의 목적이 그것이다.

---

## 1. 거부권 문턱 — 단위가 어긋나 있었다

배포된 값 `veto_below = 0.027691` 은 학습 사람의 **드래그** 밀도 하위 2% 다. 그런데
채점은 세션 단위로 들어간다(`scoring_unit="session"`). 같은 2% 를 세션 특징에서 읽으면
0.002142 로 13배 낮다.

실사용 1,135건을 다시 채점해 확인했다(기록된 점수와 **1,135/1,135 일치**).

```
veto 문턱                    오탐    veto 0점   분류기
배포값 (드래그 2%)  0.027691  18.9%    12.8%     6.2%
세션 2%             0.002142   9.9%     3.7%     6.2%
veto 없음                 -    6.2%     0.0%     6.2%
```

좌표계도 의심해서 밀도 모델을 정규화 좌표로 다시 맞춰봤다. **효과 없었다**
(9.9% → 9.7%). 수정 자체는 맞아서 남겼지만, 이득은 전부 문턱 단위에서 나온다.

### 재현하다가 걸린 것

이벤트를 `seq/event_type/t_ms/x/y` 로만 재구성하면 재현이 12.7% 밖에 안 된다.
`feature_extractor_v2._arrays` 는 `x_normalized`/`y_normalized` 를 우선 쓰고, **한
이벤트라도 그 칸이 없으면** 픽셀을 min-max 로 다시 정규화하는 다른 가지를 탄다.

`scoring_audit._SCORED_FIELDS` 주석은 그 다섯을 "추출기가 읽는 유일한 칸"이라고
적어뒀는데 사실이 아니다. **입력 지문이 맞아도 실제 채점 입력은 다를 수 있다.**
감사 지문이 지키기로 한 것을 못 지키고 있다 — 따로 고쳐야 한다.

## 2. 분류기 오탐 — 원인은 사람이 아니라 궤적 모양이었다

실사용 1,167건에서 튕긴 것과 통과한 것을 갈랐다.

```
                  튕김    통과
micro_move_ratio  0.14    0.31    미세 움직임이 없다
pause_count        1.1     5.1    멈칫하지 않는다
linearity         0.83    0.66    직선에 가깝다
event_count       13.0    20.2    경로가 짧다
```

**목표를 보고 곧장 끌어다 놓는 사람**이 봇으로 읽힌다. 그런데 그 시도들의 조준
구간은 멀쩡하다.

```
                드래그   조준    이으면
통과 (973건)     15.2    20.1     35.4
튕김 (74건)      10.9    19.2     30.1
```

근거가 없는 게 아니라 분류기가 조준을 못 보고 있었다 — 캡차 서버가 AI 로 넘기기 직전
`_EVENT_TYPE_MAP` 에 `aim_move` 가 없어 조용히 버리고 있었다.

## 3. 봇에 조준을 붙이기 — 검증이 네 번 걸렀다

사람만 조준이 있으면 모델은 "조준 있으면 사람"을 배운다. 봇에도 붙여야 한다.

위험은 붙이는 방식이 표식을 남기는 것이다. 그러면 평가 숫자만 좋아지고 방어력은
그대로다. `tools/join_aim_to_bots.py --verify` 가 이음매를 AUC 로 재고, 0.5 에서 멀면
실패로 보고한다.

```
① 이음매 간격이 사람의 2.5배     AUC 0.632   throttle 이 끝점을 떨굼
② 값들의 상관이 끊김                         변위·시간을 따로 뽑음
③ 사람보다 곧음                  AUC 0.690   헤매는 조준이 버려짐
④ 변위가 큼                      AUC 0.721   봇 드래그가 들어가는 자리만 남음
```

③은 원인을 직접 쟀다.

```
본보기를 옮겨 붙였을 때
  화면 안에 남음   1,829건   직진도 0.706
  화면 밖이라 버림    393건   직진도 0.337
  사람 전체                  직진도 0.628
```

**버리는 것이 곧 편향이다.** 평행이동은 변위·직진도·overshoot 을 바꾸지 않으니
옮기는 건 공짜다. 그래서 조준을 사람이 실제로 집었던 자리에서 만들고, 드래그를 그
끝에 붙이고, 둘을 함께 화면 안으로 민다. 버리는 경우는 **0건**이 됐다.

```
계열          이은 것   버림   이음매 최악편차   조준 본문 최고 AUC
A_linear        800      0        0.045            1.000
B_eased         800      0        0.046            0.007
C_ballistic     800      0        0.056            0.033
D_replay        800      0        0.035            0.448
```

**A·B·C 는 부드러움 하나로 갈린다**(jerk AUC 0.01~0.03). 사람 손의 미세 떨림이 없다.
학습에는 쓰되 방어력 근거로는 쓸 수 없다 — 그건 공격자가 약하다는 사실을 재는 것이다.
그래서 봇 궤적에는 전부 D_replay(진짜 사람 조준 그대로)를 붙였다.

## 5. 왜 못 넘겼나 — 사람이 10명뿐이다

`jy` 는 **멈칫하지 않는 사람**이다.

```
사람        pause_ratio
kim            0.299
ig             0.280
jk             0.242
nn             0.226
th             0.181
jy             0.091     ← 다음으로 낮은 사람의 절반
```

그 나쁜 시도 30건은 4개 세션·04:33~07:10 전체에 흩어져 있다. 일회성 사고가 아니라
평소 움직임이고, 길이도 정상이다(조준 20점 vs 나머지 16점).

멈칫 특징을 빼고 학습시켜봤지만 **jy 는 안 풀린다**(14.6% → 14.1%). 빠름·적은 멈칫·
큰 회전·높은 가속이 함께 움직여서, 하나를 빼면 모델이 나머지로 같은 판단을 한다.

문턱을 옮겨도 맞바꿈만 일어난다.

```
전체 오탐   jy 오탐   미지 봇 최악
   1.1%     5.5%       19.7%
   3.0%    14.1%        7.1%*
   5.0%    22.1%        4.7%*
```

\* 아는 공격 기준. 미지 기준은 위 §4 표를 봐야 한다.

**사람 10명 중 이 스타일이 1명뿐이라 모델이 배울 표본이 없다.** 모델을 더 만져서
넘을 수 있는 벽이 아니다. 이 스타일의 참가자 3~4명이 필요하고, 지금은 수집이 어렵다.

## 6. 그래서 무엇을 알고 켜는가

승급 캡차라 오탐의 대가가 "차단"이 아니라 **"캡차 한 번 더"** 이고, 이미 로그인 5회
실패한 사람에게만 뜬다. 그 전제 위에서 전체 오탐 3% 로 켠다.

**알고 켜는 것:**

```
1. jy 같은 사용자는 7번에 1번 캡차를 한 번 더 본다 (14.1%)
2. 처음 보는 짧은 궤적 공격은 41.3% 가 통과한다
3. 이 두 숫자는 승격 기준(3% · 10%)을 못 넘긴 값이다
```

2번이 특히 중요하다. `main_captcha_bots` 는 실서비스 길이(~14점)로 만든 유일한 계열이라
가장 현실적인 공격자이고, 그것이 처음 보는 형태로 오면 절반 가까이 통과한다.

**되돌리는 법:** `risk_policy_mode` 를 `shadow` 로 되돌리면 점수만 기록하고 아무도
막지 않는다.

```
   .venv/bin/python tools/export_aim_from_production.py \
       --password-file <file> --since '2026-08-12 04:29:00' --require-participant \
       --out data/interim/aim_production_20260812.jsonl

② 봇에 조준 붙이기 + 이음매 검증
   .venv/bin/python tools/join_aim_to_bots.py \
       --bots data/interim/<생성기>.jsonl --family D_replay \
       --out data/interim/joined/<생성기>.jsonl --verify

③ 학습 + 미지 계열 측정
   .venv/bin/python tools/train_with_aim.py \
       --version aim_overall3_20260812 --frr-mode overall --lofo
```
